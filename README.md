# Gesture Nebula

Gesture Nebula 是一个运行在浏览器中的单手手势控制 3D 粒子交互项目。用户可以通过摄像头检测手部姿态，控制星云粒子的扩散、收缩、形态切换和能量爆炸效果。

项目页面、样式、脚本、粒子逻辑和内嵌背景音乐全部包含在一个 `index.html` 中。除 CDN 库外，不需要本地构建工具或额外运行依赖。

## 功能

- 单手 MediaPipe Hands 21 点识别。
- 正掌张开：粒子向外扩散。
- 正掌握拳：粒子向中心聚拢。
- 向左快速水平划手：按顺序切换粒子形态。
- 快速握拳：触发聚拢、冲击波扩散和亮度衰减组成的 2 秒爆炸效果。
- 星云、爱心、DNA、文字四种粒子形态。
- 液体感星云球面、立体爱心心跳和文字粒子波动。
- 基于 HSL 的霓虹色彩流动与冷暖对冲。
- 粒子数量、运动速度、主色和自定义文字控制。
- 实时 FPS 和低性能提示。
- 桌面端与移动端可收起控制面板。
- 右上角 CD 背景音乐开关。
- 与 2 秒爆炸动画同步的内嵌爆炸音效，并带背景音乐自动闪避。

## 技术栈

- Three.js `0.157.0`：3D 场景和粒子渲染。
- MediaPipe Hands `0.4.1675469240`：单手 21 点识别。
- Tailwind CSS `4.3.3`：页面工具类。
- Canvas 2D：运行时生成圆形粒子光晕纹理。
- Web Audio：循环播放内嵌背景音乐。
- 原生 HTML、CSS 和 JavaScript。

所有第三方库均从固定版本 CDN 加载，项目没有本地构建步骤。

## 浏览器支持

建议使用当前稳定版：

- Google Chrome
- Microsoft Edge
- iPhone Safari
- Android 手机自带浏览器

页面依赖 WebGL、摄像头、WebAssembly 和 Web Audio。过旧或缺少这些能力的浏览器可能无法正常运行。

## 本地运行

摄像头只能在安全上下文中使用，请通过 `https://` 或 `localhost` 访问，不要直接双击打开 `index.html`。

在项目目录运行：

```bash
python -m http.server 8000
```

然后打开：

```text
http://localhost:8000/index.html
```

使用本地服务器仅是开发测试方式。运行时仍需联网加载 Three.js、MediaPipe Hands 和 Tailwind CSS CDN。

## GitHub Pages 部署

1. 将 `index.html` 和 `README.md` 上传到 GitHub 仓库。
2. 打开仓库的 `Settings` → `Pages`。
3. 选择从 `main` 分支根目录部署。
4. 等待 GitHub Pages 生成 HTTPS 地址。

项目没有构建流程，不需要 GitHub Actions、Node.js 构建或打包产物。

## 使用说明

点击左侧面板中的“开启实时追踪”并允许摄像头权限。摄像头预览会显示在右下角。

| 操作 | 效果 |
| --- | --- |
| 正掌张开 | 当前粒子形态向外扩散 |
| 正掌握拳 | 当前粒子形态向中心聚拢 |
| 镜像预览中向左快速水平划手 | 切换至下一个粒子形态 |
| 快速张开后握拳 | 触发 2 秒爆炸与重构 |
| 形态按钮 | 直接切换星云、爱心、DNA 或文字 |
| 文字输入框 | 自定义文字粒子内容 |
| 粒子数量滑块 | 调整实际粒子缓冲数量 |
| 运动速度滑块 | 调整整体动画速度 |
| 主色选择器 | 调整动态 HSL 色彩基色 |
| 全屏按钮 | 请求浏览器全屏 |
| 背景音乐 CD | 播放或暂停内嵌音乐 |

快速握拳判定窗口为 500ms，爆炸冷却为 1000ms。向左划手切换冷却为 900ms。

## 移动端

- 默认使用 6000 个粒子，桌面端默认使用 15000 个粒子。
- 控制面板默认收起，可通过左上角“控制台”按钮展开。
- 相机根据手机屏幕比例自动调整距离，使粒子形态完整进入画面。
- 横竖屏切换时会重新计算画布和相机比例。
- 手机端摄像头同样要求 HTTPS。

## 背景音乐

背景音乐以 Base64 形式嵌入 `index.html`，不需要额外上传 MP3 文件即可运行页面。

浏览器通常禁止页面在没有用户操作时自动播放有声音频，因此：

- 页面会尝试自动播放。
- 如果被浏览器拦截，音乐按钮会保持静止。
- 用户首次点击、触摸、滚动或确认键操作后会再次尝试播放。
- 点击右上角 CD 可以手动播放或暂停。

不同网站的自动播放权限相互独立，同一份页面在不同域名下可能表现不同。

快速握拳触发爆炸时，页面会同步播放 2 秒内嵌爆炸音效，并短暂压低背景音乐，随后平滑恢复。

## 安全与隐私

- 摄像头只有在用户点击“开启实时追踪”后才会申请权限。
- 应用代码没有视频录制、截图、文件上传或云端存储功能。
- 摄像头视频帧在当前浏览器内交由 MediaPipe Hands 处理。
- 关闭实时追踪后会停止摄像头媒体轨道。
- 应用代码不包含 Cookie、`localStorage`、`sessionStorage`、WebSocket、`sendBeacon` 或远程上传接口。
- 页面不包含 API Key、访问令牌、密码或私钥。
- CDN 请求会向对应 CDN 服务提供商暴露常规网络元数据，例如 IP 地址、浏览器类型和请求来源。
- 非 HTTPS 环境不会启动摄像头追踪。

## 数据与权限

本页面没有后端服务、用户账户或数据库。手势识别、粒子计算和音乐播放均在浏览器本地完成。

出于安全考虑：

- 不要将摄像头权限长期授予不可信站点。
- 不要在不信任的嵌入了本页面的网站中输入敏感文字。
- 使用完毕后可关闭实时追踪，浏览器会停止摄像头媒体流。

## 已知限制

- 仅支持单手识别，不包含双手模式。
- 不同设备、光线和手掌朝向可能影响手势识别稳定性。
- MediaPipe、Three.js 和 Tailwind 依赖网络 CDN。
- 浏览器可能阻止背景音乐自动播放。
- iPhone Safari 的全屏 API 支持情况与其他浏览器不同。
- 内嵌背景音乐和爆炸音效使 `index.html` 体积约为 7.6MB，移动网络首次加载可能较慢。
- 性能目标为桌面端约 55 FPS 以上、移动端约 30 FPS 以上，实际帧率取决于设备。
